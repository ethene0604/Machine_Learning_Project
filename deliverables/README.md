# A/B 实验交付包

该目录用于交给报告和 PPT 同学，分为以下部分：

- `figures/report/`：完整报告版图片，PNG，300 dpi；
- `figures/ppt/`：适合幻灯片的高分辨率图片；
- `tables/`：实际运行生成的 CSV 表格；
- `notes/data_and_methods.md`：数据、划分、预处理、模型和评价方法；
- `notes/result_findings.md`：可直接用于结果分析与讨论的真实结论；
- `notes/figure_captions.md`：每张图的建议图注和分析重点；
- `notes/table_summary.md`：便于直接复制到报告的指标表；
- `notes/student_a_handoff.md`：同学 B 和报告/PPT 同学的交接清单。
- `notes/student_b_handoff.md`：随机森林实验设置、主要结果、图注和核对说明；
- `tables/final_metrics.csv`：A/B 现有测试指标的统一表格；
- `tables/table_13_all_validation_metrics.csv`：所有候选在同一验证集上的比较；
- `tables/table_14_all_feature_ablation.csv`：线性模型与随机森林的比例特征消融。

报告和 PPT 中的数字必须来自本目录和 `results/metrics/`，不要手工修改指标。
