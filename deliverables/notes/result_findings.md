# 实验结果与解读

完整精度数据见 `../tables/table_13_all_validation_metrics.csv` 和
`../tables/final_metrics.csv`。全体验证集最优为原始特征优化随机森林。

## 模型选择

在线性模型候选中，验证集 RMSE 最低的是“Linear Regression + 原始特征 +
三个比例特征”。全体候选中，原始特征优化随机森林的验证 RMSE 最低，为 0.5176。

| 模型 | 特征方案 | 验证 MAE | 验证 RMSE | 验证 R² |
|---|---|---:|---:|---:|
| Linear Regression | 原始 + 比例 | 0.4918 | 0.6809 | 0.6442 |
| Ridge Regression | 原始 + 比例，alpha=100 | 0.4919 | 0.6816 | 0.6434 |
| Ridge Regression | 原始，alpha=3 | 0.5334 | 0.7354 | 0.5848 |
| Linear Regression | 原始 | 0.5335 | 0.7354 | 0.5848 |
| RF 基线 | 原始 | 0.3388 | 0.5196 | 0.7927 |
| RF 优化 | 原始 | 0.3376 | 0.5176 | 0.7944 |

## 最终测试结果

| 模型 | MAE | MSE | RMSE | R² |
|---|---:|---:|---:|---:|
| Linear Regression + 原始特征 | 0.5210 | 0.5203 | 0.7213 | 0.6066 |
| Ridge + 原始特征 | 0.5210 | 0.5201 | 0.7212 | 0.6067 |
| Linear Regression + 比例特征 | 0.4735 | 0.4195 | 0.6477 | 0.6828 |
| Ridge + 比例特征 | 0.4737 | 0.4212 | 0.6490 | 0.6815 |
| RF 优化 + 原始特征 | **0.3224** | **0.2385** | **0.4884** | **0.8196** |

Linear Regression 加入比例特征后，测试集 RMSE 从 0.7213 降至 0.6477，
下降 10.21%；R² 从 0.6066 提高到 0.6828，增加 0.0762。验证集上 RMSE
下降 7.42%，说明改善不是只出现在测试集上的偶然现象。

比例特征对线性模型有效，可能因为它们显式表达房屋结构与居住密度关系；
随机森林加入同样特征后验证 RMSE 略升，可能是树模型已能从原始变量学习
部分非线性关系，新增比例变量没有提供额外有效信息。

## 随机森林分析

原始特征基线的验证 RMSE 为 0.5196，五折调参后为 0.5176，改善约 0.40%。
最优参数为 80 棵树、最大深度 20、最小叶节点样本数 2、每次分裂使用 70% 特征。
训练 RMSE 约 0.2494，仍明显低于验证 RMSE，说明存在一定过拟合。
验证集 permutation importance 以 `MedInc`、`Latitude`、`Longitude` 和
`AveOccup` 最高，描述的是模型依赖，不代表因果作用。

## Ridge 分析

原始特征上的 Ridge 在 alpha=3 附近略有提升，但幅度极小；比例特征上的 Ridge
选择 alpha=100，测试 RMSE 为 0.6490，与无正则化的 Linear Regression
基本持平且略差。说明当前特征和样本规模下，L2 正则化没有带来明确泛化收益，
反而可能轻微限制模型拟合能力。

## 从零实现验证

NumPy Ridge 使用 `alpha=100`、`lambda=alpha/m=0.0069214`、学习率 0.05，
在 3,708 次迭代后收敛。训练集、验证集和测试集的 RMSE、MAE、R²
与 Scikit-learn Ridge 在小数点后 6 位以内一致，说明梯度推导和正则项换算正确。

## 误差规律

按真实房价区间统计测试集误差：

| 真实房价区间 | 样本数 | RMSE | 平均偏差（预测-真实） |
|---|---:|---:|---:|
| 低于 1.5 | 1,124 | 0.5267 | +0.2839 |
| 1.5～3.0 | 1,394 | 0.4479 | +0.0842 |
| 3.0～4.99 | 437 | 0.9470 | -0.6757 |
| 大于等于 4.99 | 141 | 1.4955 | -0.9292 |

表中是最佳线性候选的测试误差。锁定随机森林在 ≥4.99 高价截断段的 RMSE
约 1.0310、平均预测偏差约 −0.7200，虽然有所改善，仍存在明显低估。
目标值上界截断以及区域级统计特征限制了高价段的预测和解释。

## 局限

- 随机森林随机搜索每种特征方案只抽取 6 组参数，调参覆盖有限；
- 标准化系数描述模型关联，不代表因果关系；
- 比例特征与原始特征存在相关性，线性系数不能孤立解释；
- 未引入外部交通、学校、海岸线等地理信息；
- 数据为区域级统计值，无法反映单套房屋差异；
- 高价区域和截断值附近误差显著更大。
